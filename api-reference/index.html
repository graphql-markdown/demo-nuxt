Workspace API

The workspace API manages folders, projects and the users who own them, and streams project and folder changes as they happen.

Every operation comes with a ready-to-run example: the query, the variables it takes, and the response it returns — see folder for a start.

QUERY
query SearchWorkspace($query: String!) {
  search(query: $query) {
    __typename
    ... on Folder {
      id
      name
    }
    ... on Project {
      id
      name
      status
    }
    ... on User {
      id

      email
    }
  }
