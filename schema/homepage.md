---
title: Workspace API
description: GraphQL reference for the workspace demo schema — folders, projects, users, and their live events.
---

The workspace API manages **folders**, **projects** and the **users** who own them, and streams project and folder changes as they happen.

Every operation comes with a ready-to-run example: the query, the variables it takes, and the response it returns — see [`folder`](#queries-folder) for a start.
